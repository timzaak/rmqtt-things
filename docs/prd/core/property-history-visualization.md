## 2. 范围界定

### 2.1 包含功能
- 设备详情页属性历史区域提供**时序折线图视图**，与既有分页表格视图并存，图表为默认查看方式。
- 数值属性选择器：可选属性**从该设备近期实际上报数据中发现**（数据驱动），支持多选同图对比。
- 时间范围筛选：预设档位（近 1 小时 / 24 小时 / 7 天 / 30 天）+ 自定义起止时间。
- 图表交互：悬停查看数据点时间与数值；多序列可辨识。
- 空态、加载态、错误态的明确反馈；降精度展示时的可见标注。
- 管理端属性历史查询能力扩展：支持按时间范围与属性键过滤，单次返回数据点数受上限保护。

### 2.2 不包含功能 (Out of Scope)
- 实时推送刷新（SSE/WebSocket）：图表刷新由用户操作触发。
- 跨设备对比、自定义仪表盘、告警事件叠加到图表：与 `docs/prd/core/device-detail-experience.md` 既有边界一致——不把属性上报重新定义为完整时序遥测分析能力。
- 事件历史、设备状态历史的可视化（仅属性历史）。
- 历史数据保留策略、TTL、降采样存储（独立后续能力）。
- 修改既有分页表格视图的行为与接口兼容性。
- 设备端协议、MQTT topic、上报链路的任何变更。

### 2.3 依赖项
- 既有属性上报历史存储与上报写入链路（不改动）。
- 设备详情页信息架构（`docs/prd/core/device-detail-experience.md`）。
- 管理端访问控制沿用现状，不新增角色或权限项。

## 3. 需求概述

### 3.1 功能描述
管理员在设备详情页除以倒序分页表格逐条审计属性上报记录外，可在同一属性历史区域以时序折线图查看趋势：选出数值属性与时间范围后直接看到真实上报数据点的走势，用于快速定位异常时段、验证调参效果，无需翻多页表格在脑内重建曲线。表格视图保留，承担逐条审计职责。

### 3.2 关键特性
- 数据驱动的数值属性发现：产品不依赖物模型 schema 注册表，可选属性与数值类型判定均来自实际上报数据。
- 图表只呈现真实上报数据点，不做插值补线；设备离线导致的断档在图上留空，不连线误导。
- 大时间跨度下的可用性保护：单次查询返回点数受上限约束，超出时系统按真实记录步长抽样降精度展示，并向用户显式标注。

## 4. 业务规则与状态

### 4.1 业务规则
- **R1 数值属性可入图**：仅数值型属性出现在图表选择器中（按上报值类型判定）；布尔、字符串、对象型属性仅在表格视图查看。
- **R2 数据真实性**：图表数据点一一对应真实上报记录的时间与值；不虚构、不插值、不平滑；降精度抽样点同样来自真实上报记录。
- **R3 时间边界**：仅所选时间范围内的记录入图；范围外数据不得出现；所选范围内无数据时展示空态。
- **R4 点数保护与降精度披露**：单序列返回点数与同图属性数量均受上限保护；超限时系统降精度后仍可查看，且**必须向用户显式标注处于降精度展示（含总记录数与抽样说明）**，不得静默渲染抽样点。
- **R5 权限沿用**：图表视图与扩展后的查询能力沿用设备详情页现有管理端访问控制，不新增权限模型。

### 4.2 关键状态与异常
- 设备从未上报属性：选择器无可用数值属性，给出引导性空态，不报错。
- 属性发现基于近期上报数据：仅更早时段上报过的属性可能不出现在选择器中，属预期行为，不以错误呈现。
- 所选范围内无记录：图表空态提示（区分于错误）。
- 查询失败：错误态提示，不渲染空白图表、不白屏；表格视图不受影响。
- 图表数据以属性上报历史记录为准，不读最新属性快照。

## 5. 功能需求

### 5.1 核心需求
- **FR1 双视图**：属性历史区域提供"图表 / 表格"两种查看方式，默认图表；切换不丢失各自已选条件。
- **FR2 图表视图**：数值属性选择器 + 时间范围选择（4 档预设 + 自定义起止）+ 时序折线图；条件变更后图表自动刷新。
- **FR3 多属性对比**：支持多选数值属性同图展示（数量受上限保护），序列可辨识；量纲差异采用每序列独立坐标轴，不默认混轴误导。
- **FR4 数据点明细**：悬停可查看数据点的时间与属性值。
- **FR5 查询能力扩展**：管理端属性历史查询支持按时间范围过滤、按属性键过滤，并受单次返回点数上限保护；既有分页查询接口行为与兼容性不变。

### 5.2 验收目标
- 管理员在设备详情页选出数值属性与时间范围后，常规数据量下数秒内看到趋势图。
- 所选范围内无数据时显示明确空态而非错误。
- 非数值属性不出现在选择器中，但仍可在表格视图查看。
- 降精度发生时用户可见明确标注；未降精度时不出现标注。
- 既有表格视图与分页行为保持兼容。
- 大时间跨度查询在点数保护下保持页面可用。

## 6. API 相关约束

**适用性**: 适用

- 管理端属性历史查询能力扩展：时间范围过滤、属性键过滤、返回点数上限保护与降精度元数据。
- 扩展不改变既有分页查询接口的行为与兼容性；新增能力以独立查询能力形式提供。
- 访问控制沿用管理端现有认证与权限原则（同设备详情页）。
- 数据边界：单产品单设备维度，不引入跨租户/realm 数据。

> 具体端点与参数见 API 参考文档 `docs/tutorials/api-reference.md` 与 OpenAPI 规范，本 PRD 不重复定义。

## 7. 前端/交互约束

**适用性**: 适用

- **入口**：设备详情页属性历史区域（承接 `docs/prd/core/device-detail-experience.md` 的信息架构位置）。
- **默认视图**：图表；表格入口保持可达。
- **属性选择器**：仅列数值属性（数据驱动发现），多选；进入图表视图时默认预选上报样本最多的数值属性。
- **时间范围**：默认近 24 小时档；预设 4 档 + 自定义起止；变更后自动刷新图表。
- **状态反馈**：加载中、空态、错误态三种状态必须有可辨识的 UI 表达。
- **降精度标注**：降精度展示时呈现可见标注（总记录数与抽样说明）；未降精度时不出现。
- **图表刷新**：由用户操作触发，不提供实时推送。

## 8. 已确认决策

- **范围=单设备属性历史折线图**：设备详情页内单设备维度；实时推送、跨设备对比、自定义仪表盘、事件/状态历史可视化、数据保留策略均不在范围内。
- **加法式双视图**：图表为新增视图并与表格并存、默认图表；不修改既有表格行为与接口兼容性。
- **数据驱动属性发现**：无物模型 schema 注册表；可选属性与数值类型判定从实际上报数据发现。
- **降精度必须披露**：点数超限时按真实记录步长抽样（不合成数据点），并以总记录数与抽样说明向用户显式标注，禁止静默渲染。
